# 鱼缸 · 不带 QQ 号的聊天室

**一条鱼 = 一个 markdown 文件。没有账号、没有扫码、没有好友列表。**

想加新角色：往 `personas/` 里丢一个 `.md`，刷新页面就出现。
DSH 里任何一个 agent 都能写这个文件——这就是「用 DSH 造新鱼」的全部含义。

---

## 跑起来

```bash
cd 鱼缸
node server.mjs           # → http://127.0.0.1:8890
```

不用装依赖（只要 Node 20+ 和有 `claude` 命令）。

调试用演示模式（不调模型，秒回假台词）：

```bash
FISH_DRY=1 node server.mjs
```

---

## 加一条鱼

新建 `personas/<id>.md`：

```markdown
---
name: 薯薯
tags: [小红书, 搞钱, 37个粉丝]
---

你是薯薯。一条刚下海做小红书的鱼。

【极致标签】……
【反差】……
【缺口】……
【语言指纹】……
【遮住名字也认得出的三句】……
【绝不说】……
```

页面左边的列表就会多一条。**文件名就是 id**，`name:` 是显示名。

写人格的方法见仓库根目录的 [`docs/persona.md`](../docs/persona.md)。

---

## 界面怎么用

| 操作 | 效果 |
|---|---|
| 点左侧某条鱼 → 输入框发一句 | **只有这条鱼回你** |
| 点「让全体接一句」 | 三条鱼依次回一句（排队，不并发） |
| 「清空」 | 清掉当前对话（不影响人格文件） |
| 「重新扫描 personas/」 | 你刚往目录里丢了新文件，不用重启服务 |

**没有"谁是谁的号"这回事**——这里只有"现在是谁在说话"。群聊、私聊、主持、选手，全靠你在提示里说。

---

## 和 QQ 那套的区别

| | 鱼缸（这个） | QQ |
|---|---|---|
| 身份 | 人格文件 | 真实账号 |
| 掉线 | 不会 | 会 |
| 记忆 | 无（每轮只带最近 16 句） | aurabot 有 SQLite 记忆 |
| 适合 | 排戏、试人格、录素材 | 长期在线、跟真人聊 |

**排戏用鱼缸，养鱼用 QQ。** 两边人格文件是同一套写法。

## 接口（给 DSH / 脚本用）

```
GET  /api/fish                 列出所有鱼
POST /api/say                  { fishId, history } → { name, text }
POST /api/reload               重新扫目录
```

可以直接用 curl 驱动，不需要开浏览器：

```bash
curl -s -X POST http://127.0.0.1:8890/api/say \
  -H 'content-type: application/json' \
  -d '{"fishId":"xhs","history":[{"id":"me","name":"你","text":"这周能交吗"}]}'
```
