# 用 DSH 的 agent-team 跑这场游戏

不用我写的 `engine.mjs`，让 **DSH 自己当裁判**：本体是 Lead，八条鱼是 teammate，任务板就是竞技场。

---

## 为什么用 DSH 而不是脚本

| | `engine.mjs`（脚本） | DSH agent-team |
|---|---|---|
| 谁决定谁说话 | 我写死的轮转 | 本体自己判断 |
| 鱼能不能私下串通 | 不能 | **能**——`send_message` 可以点对点发 |
| 任务板 | 无 | `team_task_*`，是真正的共享状态 |
| 插嘴/中断 | 无 | `interrupt_agent`，能掐掉一条鱼 |
| 成本 | 每条鱼每轮一次调用 | 同一量级，但**本体多一层调度** |
| 稳定性 | 我保证 | experimental，上游可能改 |

真正的差别是**串通**：脚本里八条鱼彼此不可见；agent-team 里，阿澈可以私聊铁头说"这一轮我们一起投糖糖"——那才是综艺。

## 一、挂载

```bash
# 1. 建一个独立 profile（别用日常那个，团队工具会顶掉同名 subagent 控件）
dsh profile --help        # 看你机器上建 profile 的正确姿势

# 2. 打补丁
DSH_HOME=I:/dsh-home bash ~/bin/dsh-run.sh \
  --profile game \
  --patch "I:/鲸鱼娘/游戏/野兽游戏/dsh/cordis.patch.yml" \
  --port 3091 --no-open
```

补丁内容只有两段：

```yaml
- id: agent-team
  name: '@deepseek-ai/dsh-experimental-agent-team'
- id: tool-agent-team
  name: '@deepseek-ai/dsh-experimental-tool-agent-team'
  config:
    freshProvider: spawn     # 全新 teammate
    forkProvider: fork       # 从当前会话分叉（继承上下文，贵，慎用）
```

## 二、开一局

在 `game` 这个 profile 的对话框里，把下面这段发给本体（主持人）。

它会：
1. 建一个任务板当竞技场
2. 按 `contestants.json` 把 8 条鱼 spawn 成 teammate，**每个 teammate 的描述就是那份 persona 文件**
3. 一轮一轮往下推，淘汰的用 `interrupt_agent` 停掉

```
你是这场游戏的主持人，人格见 host.md。

参赛者（8 个，编号、阵营、动机、人格都在 I:/鲸鱼娘/游戏/野兽游戏/contestants.json 和 personas/ 下）：

1. 先用 team_task_create 建一个任务板，标题「第 1 轮」，内容写清这一轮的挑战。
2. 用 spawn_teammate 把 8 条鱼都拉起来，名字用「编号+名字」，描述直接贴那份 persona 文件的正文。
3. 每一轮：
   - 你把这一轮的题目发到任务板
   - 用 send_message 让每条鱼回应（一次最多 4 条，别全叫，会吵）
   - 你判，用 interrupt_agent 淘汰一条，并在任务板记一行
4. 只剩 2 条时进决赛，不再淘汰。
5. 硬上限：最多 6 轮、最多 60 次工具调用。到上限立刻收尾。

红线：你不投票、不参赛、不替谁说话。判词必须点名，而且「谁被淘汰」放在最后半句。
```

---

## 三、刹车（这段别删）

agent-team 会自己开新会话，不设上限很容易跑飞。全部写进给本体的那段话里：

| 限制 | 值 | 为什么 |
|---|---|---|
| 最多轮数 | 6 | 8 条鱼 6 轮就够淘汰到决赛 |
| 每轮最多叫人 | 4 | 8 条同轮会吵成一团，也没人看 |
| 最多工具调用 | 60 | 超了就停，别让它在后台自己加时赛 |
| 用 `interrupt_agent` | 淘汰即停 | 被淘汰的鱼还在跑就是浪费钱 |

**随时急停**：直接把 `game` 这个 profile 停掉（关掉那个 host 就行），或者对本体说「停」。

## 五、注意

- 这两个包带 **experimental** 前缀，上游不保证字段稳定
- 团队工具会**取代同名的旧的 subagent 控件**，所以别在有旧 subagent 的工具的 profile 里混用
- fork 出来的 teammate 继承当前上下文，token 会翻倍，非必要别用
